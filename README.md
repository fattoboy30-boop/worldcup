# FIFA World Cup 2026 - United North America

An engaging, interactive webpage for FIFA World Cup 2026, designed to captivate Facebook followers with comprehensive tournament content.

## Features

- **Live Countdown** - Real-time countdown to tournament kickoff
- **48 Teams** - All qualified nations with confederation filtering
- **16 Host Cities** - Venues across USA, Canada, and Mexico
- **Star Players** - Featured players carousel
- **Match Schedule** - Key fixtures including opening and final matches
- **World Cup History** - Interactive timeline of legendary moments
- **Fan Zone** - Polls, quizzes, and social sharing
- **Facebook Integration** - Optimized for social sharing with Open Graph tags

## Sections

1. **Hero** - Animated landing with countdown and stats
2. **Host Cities** - 16 venues across 3 nations
3. **Teams** - Filterable grid of 48 qualified teams
4. **Schedule** - Match fixtures by tournament stage
5. **Star Players** - Featured athletes carousel
6. **History** - World Cup timeline from 1930-2022
7. **Fan Zone** - Interactive polls, quizzes, and facts
8. **Newsletter** - Email subscription form

## Facebook Optimization

- Open Graph meta tags for rich previews
- Share buttons for Facebook and Twitter
- Mobile-responsive design
- Fast loading for better engagement

## How to Use

1. Open `index.html` in a web browser
2. Or deploy to GitHub Pages for public access

## Deployment to GitHub Pages

```bash
git remote add origin https://github.com/fattobiy30/worldcup.git
git push -u origin main
```

Then enable GitHub Pages in repository settings.

## Technologies

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Oswald, Roboto)
